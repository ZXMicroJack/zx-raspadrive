RaspaDrive Firmware
-------------------

v1.2
----
- Handle SD card not being inserted better
- added 5th button on production model

v1.1
----
- Added YM2149 soundchip emulation.
- Fixed bug with F12 on USB keyboard causing boot to ROM.

v1.0
----
- First revision
- includes: 
	- DivIDE emulation with 2 drives (SD/MMC and USB disk)
	- +3 disk emulation
	- +2a
	- USB joypads (as Kempston joystick)
	- Kmouse (Kempston mouse)
	- USB keyboards (48k, 128k, +2 grey... NOT +2A / +3 due to gate array)
	- Opus Discovery (1 drive only)
	- Loader menu for joypad calibration, loading hardware modes, 
	- System ROM / Cartridge ROM emulation.
